# N-Queens: Empirical Benchmark of Exact Solving Methods
**Course:** Modern Topics in Computer Science (INT3011E) — VNU-UET  
**Author:** Do Xuan Bang — 24021383

# Overview
Comprehensive benchmark comparing **12 solver configurations** across three exact solving paradigms for the N-Queens problem:
- **SAT Solving** — 5 At-Most-One encodings: Binomial, Binary, Sequential Counter, Commander, Product
- **Constraint Programming** — Pure Backtracking, OR-Tools CP-SAT (Integer & Boolean), IBM CPLEX CP
- **Integer Linear Programming** — Gurobi MIP, IBM CPLEX MIP, SCIP
